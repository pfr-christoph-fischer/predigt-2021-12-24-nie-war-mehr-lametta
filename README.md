# Nie war mehr Lametta

Irgendwie seltsam, dieses Weihnachten. Klein, fast mickrig. So vieles, was sonst dazugehörte, geht diesmal nicht. Traurig. Früher war mehr Lametta. Echt? Weihnachten war schon immer klein. Das ist ja gerade das Geheimnis, dass der unendliche Gott ein kleiner Mensch wird, um zu den kleinen Menschen zu kommen, die er liebt.
